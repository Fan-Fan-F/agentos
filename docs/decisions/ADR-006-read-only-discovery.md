# ADR-006：发现与认证只读；绝不代登录、绝不碰凭据内容

- 状态：Accepted（2026-09-18；用户指令强化）
- 决策：
  1. Agent 发现只做**存在性扫描**：PATH 目录逐个 stat 可执行名、npm 全局根目录匹配包名、家目录标记文件 stat（如 `~/.claude.json`、`~/.codex/auth.json`）。**不读取任何凭据文件内容，不上传、不复制、不迁移 Token。**
  2. 版本探测需要 spawn `<bin> --version`，默认**关闭**（`scan({probe:true})`，UI 里是用户点击"深度检测"才触发）——编排器不得在用户不知情时执行其已装 agent。
  3. 已登录状态由原厂 agent 自有机制管理；AgentOS 只报告"检测到登录标记/未检测到/未知"，不要求也不协助重新登录。
  4. 安装中心只给官方源命令预览（npm registry 官方包名），真实安装必须用户显式确认。
- 背景：用户明确指示"不要动我现有的 agent，不要损害和修改我现在的东西"；与研究结论（认证由原厂管理）一致。
